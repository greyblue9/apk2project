Packaging policy
----------------
The release archive intentionally excludes generated/precompiled .class output,
java_engine/classes/, javac_engine/build/, Python __pycache__, and *.pyc. These
are compiled/generated on demand and are covered by .gitignore.

not repeated here because the complete Android SDK/pinned-download runtime from
the user's Termux environment is not present in this sandbox. The preceding
v28.8 build was user-verified to install and launch; v29 retains those runtime
semantics and the affected regression gates pass here.
